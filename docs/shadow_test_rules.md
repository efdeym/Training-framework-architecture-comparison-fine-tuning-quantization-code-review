# Gölge Test (Shadow Test) Kuralları

Bu belge **B22** görevi kapsamında hazırlanmıştır.

## 1. Kaynak ve Lisans Kuralları
- **İzin Verilen Kaynaklar:** iNaturalist (CC0, CC-BY, CC-BY-NC), Wikimedia Commons, Unsplash.
- **Yasak Kaynaklar:** Filigranlı stok siteleri ve telif durumu belirsiz arama motoru görselleri.

## 2. Kalite Kriterleri
- Çözünürlük: Kısa kenar >= 224 piksel.
- Format: `.jpg` veya `.jpeg`.
- Çeşitlilik: Farklı çekim açıları, doğal ışık ve karmaşık arka planlar tercih edilmelidir.

## 3. Dizin Yapısı
Görseller ilgili sınıf numarası klasörüne yerleştirilir:
`data/shadow_test/<sınıf_no>/*.jpg`
